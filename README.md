A museum label a museum in the year 3000 puts beside an ordinary object from today: a password sticky note stuck to a monitor.

> Password sticky note, c. 2025. The secret word was written down and stuck to the monitor, so anyone passing could read it. Security was a ritual.

`main.ts` (Node 22, standard library only) writes the label to `/output/entry.txt` and verifies it byte-for-byte against its sha256.
